# pokemon-chatbot-rag
Built a pokemon chatbot using RAG, llama3.1:8b, and nomic

data sourced from: <https://medium.com/@hanicierlak/talk-to-your-data-with-retrieval-augmented-generation-rag-or-how-i-built-a-pok%C3%A9mon-chatbot-2beb2457851a>

Instructions:
 - Clone repository to local machine
 - Have python, llama3.1:8b, and nomic-embed-text installed
 - Run src/ingest.py to ingest poke-corpus.csv to vector database
 - Run src/query.py to start chatbot up
